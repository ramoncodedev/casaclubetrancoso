# Casa Clube Trancoso

Site institucional do Casa Clube Trancoso (beach club na Praia do Rio Verde, Trancoso-BA).

Site estático (HTML, CSS e JS), sem build. Basta abrir `index.html` ou publicar a pasta (Vercel, Netlify, GitHub Pages).

- `index.html`: página principal
- `cardapio.html`: cardápio completo (dados em `menu.js`)
- `style.css` / `script.js`: estilos e comportamento
- `img/`: fotos e logo
